**آموزش جامع و عملی راه‌اندازی سرور ماینکرفت (نسخه جاوا)**

سلام بچه‌ها\! داشتن یه سرور اختصاصی ماینکرفت یعنی پادشاهی کردن تو دنیای خودمون. اینکه بتونیم قوانین رو خودمون بذاریم، پلاگین‌های خفنی که دوست داریم رو نصب کنیم و با رفقا یه مپ کاملاً شخصی‌سازی‌شده بسازیم، آرزوی هر پلیریه. من خودم بارها این مسیر رو رفتم و تو این راهنما می‌خوام قدم‌به‌قدم و خیلی دقیق بهتون یاد بدم چطور روی سیستم شخصی خودتون (ویندوز) یه سرور ران کنید.

**پیش‌نیازهای راه‌اندازی (چی لازم داریم؟)**

* **سیستم مناسب:** حداقل ۴ گیگابایت رم (که ۲ گیگش رو باید اختصاصی بدیم به سرور) و یه پردازنده متوسط که کم نیاره.  
* **اینترنت پایدار:** برای اینکه میزبان خوبی برای بقیه پلیرها باشید و وسط فایت دیسکانکت نشن، اینترنتتون باید پینگ خوب و قطعی کمی داشته باشه.

**مرحله اول: نصب نسخه صحیح جاوا (Java)** همون‌طور که می‌دونید ماینکرفت با زبان جاوا نوشته شده، پس سیستم شما برای اجرای سرور بهش نیاز داره. اگه مثل من قصد دارید جدیدترین نسخه‌های ماینکرفت (مثلاً ۱.۲۰ به بالا) رو ران کنید، حتماً باید Java 21 رو نصب کنید.

1. عبارت *Java 21 JDK download* رو گوگل کنید و از سایت رسمی Oracle دانلود و نصبش کنید.  
2. برای اینکه مطمئن بشید درست نصب شده، Command Prompt (CMD) ویندوز رو باز کنید و دستور `java -version` رو تایپ کنید. اگه نصب درست باشه، نسخه جاوا رو بهتون نشون میده.

**مرحله دوم: دانلود هسته سرور** شما می‌تونید نسخه رسمی (Vanilla) رو از خود سایت ماینکرفت دانلود کنید، اما بین خودمون باشه، برای جلوگیری از لگ و اینکه بتونید بعداً پلاگین نصب کنید، به شدت پیشنهاد می‌کنم از نسخه‌های بهینه‌شده استفاده کنید.

1. برید تو سایت **PaperMC.io**.  
2. از بخش Downloads، جدیدترین نسخه Paper که به ورژن بازیتون می‌خوره رو دانلود کنید.  
3. یه پوشه جدید تو دسکتاپ یا هر درایوی که جا داره به اسم `Minecraft Server` بسازید و فایلی که دانلود کردید (فایل .jar) رو بندازید توش. برای راحتی کار، اسم فایل رو به `server.jar` تغییر بدید.

**مرحله سوم: اجرای اولیه و تایید قوانین (EULA)**

1. روی فایل `server.jar` دو بار کلیک کنید.  
2. چند ثانیه صبر کنید. می‌بینید که چندتا فایل جدید تو پوشه ساخته میشه و بعدش عملیات متوقف میشه. نترسید، این کاملاً طبیعیه\!  
3. فایلی به اسم `eula.txt` تو همون پوشه ایجاد شده. با نوت‌پد بازش کنید.  
4. عبارت `eula=false` رو پیدا کنید و بکنیدش `eula=true` و فایل رو سیو کنید. با این کار به ماینکرفت میگیم که قوانینش رو قبول داریم.

**مرحله چهارم: ساخت فایل راه‌انداز سرور اختصاصی (Bat File)** برای اینکه بتونیم به سرورمون رم اختصاص بدیم و مدیریتش کنیم، باید یه فایل رانر بسازیم:

1. داخل پوشه سرور، کلیک راست کنید و یه فایل متنی جدید (Text Document) بسازید.  
2. بازش کنید و این کد رو دقیقاً توش کپی کنید:

DOS  
java \-Xmx2G \-Xms2G \-jar server.jar nogui  
pause

*(نکته: عبارت 2G یعنی ۲ گیگ رم دادیم به سرور. اگه سیستمتون غوله می‌تونید بکنیدش 4G).* 3\. از منوی File روی Save As کلیک کنید. 4\. بخش Save as type رو روی All Files قرار بدید و اسم فایل رو `start.bat` بذارید و سیو کنید. 5\. حالا اون فایل متنی اولیه رو پاک کنید. از این به بعد برای روشن کردن سرور فقط کافیه روی همین `start.bat` دو بار کلیک کنید.

**مرحله پنجم: تنظیمات شبکه و Port Forwarding (غول مرحله آخر\!)** رسیدیم به بخش چالش‌برانگیز ماجرا یعنی ارتباطات شبکه. راستش اون علاقه و مهارتی که به مباحث کلاس‌های شبکه تو دوران مدرسه داشتم، دقیقاً واسه همین روزا و باز کردن پورت‌ها به دردم خورد\! برای اینکه دوستاتون بتونن از خونه خودشون به سروری که روی سیستم شماست وصل بشن، باید پورت ماینکرفت رو تو مودمتون باز کنید.

1. **پیدا کردن IP داخلی:** تو ویندوز CMD رو باز کنید و دستور `ipconfig` رو بزنید. عددی که جلوی IPv4 Address نوشته شده (مثلاً 192.168.1.10) رو یه جا یادداشت کنید.  
2. **ورود به تنظیمات مودم:** تو مرورگرتون آدرس مودم (معمولاً 192.168.1.1) رو وارد کنید و با یوزر و پسورد (اغلب admin) لاگین کنید.  
3. **باز کردن پورت:** دنبال بخشی به اسم Port Forwarding یا Virtual Server یا NAT بگردید.  
4. یک رول جدید بسازید:  
   * **Port:** عدد 25565 (پورت پیش‌فرض بازی) رو برای هر دو حالت Internal و External وارد کنید.  
   * **IP Address:** همون آدرس IPv4 که تو مرحله اول یادداشت کردید رو بزنید.  
   * **Protocol:** بذاریدش روی حالت TCP/UDP (یا Both) و تنظیمات رو سیو کنید.

**مرحله ششم: ورود به سرور و مدیریت آن** حالا فایل `start.bat` رو اجرا کنید و منتظر بمونید تا کلمه `Done` تو اون پنجره مشکی‌رنگ کنسول نوشته بشه. سرور شما روشنه\!

* **برای ورود خودتون:** برید تو بازی (بخش Multiplayer)، روی Add Server کلیک کنید و تو بخش Server Address کلمه `localhost` رو بنویسید.  
* **برای ورود دوستاتون:** تو گوگل سرچ کنید *What is my IP*. یه آدرس IP عمومی بهتون میده. این آدرس رو بفرستید برای دوستاتون تا تو بخش Server Address وارد کنن و بیان تو مپ شما.  
* برای اینکه تو بازی ادمین بشید و دسترسی کامل داشته باشید، تو همون پنجره مشکی سرور دستور `op YourUsername` رو تایپ کنید تا کنترل کامل دستورت دستتون بیاد.

### **راهکار جایگزین برای یک تجربه بدون لگ (پیشنهاد خودم)**

ببینید بچه‌ها، همون‌طور که تو این آموزش دیدید، راه‌اندازی سرور خانگی نیازمند انجام تنظیمات شبکه، درگیر شدن با مفاهیمی مثل Port Forwarding و از همه مهم‌تر، روشن موندن مداوم سیستمه. به عنوان کسی که این مسیرو رفته بهتون میگم، اگه سیستم قدرتمندی برای میزبانی ندارید یا پینگ اینترنتتون برای بازی گروهی مناسب نیست و دوستاتون همش لگ میشن، اصلاً نیازی نیست قید بازی رو بزنید.

استفاده از خدمات و سرورهای آماده [**هلیکس گیم**](https://helixgame.ir/) این امکان رو به شما میده که تمام این محدودیت‌های سخت‌افزاری و شبکه‌ای رو دور بزنید. به جای اینکه خودتون رو درگیر کارهای فنی و افت پینگ کنید، سرور رو آماده تحویل می‌گیرید و یه تجربه فوق‌العاده روان، حرفه‌ای و بدون قطعی تو ماینکرفت خواهید داشت. تمرکزتون رو بذارید روی بیلد کردن و بازی با رفقا، نه رفع ارورهای شبکه\!
